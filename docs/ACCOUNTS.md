# Project accounts

| Service | What the project uses it for | Dashboard |
| --- | --- | --- |
| GoDaddy | Registration and DNS for `cadenceapp.org`, plus billing for its Microsoft 365 email plan. Manage incoming mail in Outlook. | [GoDaddy products](https://account.godaddy.com/products) · [Outlook](https://outlook.office.com/mail/) |
| Resend | Outgoing transactional email. The intended sender for Change email confirmations is `info@cadenceapp.org`. As of November 13, 2026, the owner reports domain setup complete. The owner reported receiving codes. Account email changes are now paused. | [Sending domains](https://resend.com/domains) |
| Supabase | Authentication, database and Edge Functions. Staging and production are separate projects. Each has its own Auth email and phone provider settings. | [Supabase projects](https://supabase.com/dashboard/projects) |
| Twilio | Twilio Verify for SMS codes when users add or change a phone number. | [Twilio Console](https://console.twilio.com/) |
| Expo / EAS | iOS cloud builds, build credentials, environment variables and submissions to App Store Connect. | [Project builds](https://expo.dev/accounts/kratijain26/projects/period-app/builds) |
| Apple Developer | Membership, signing and Sign in with Apple. App Store Connect uses the same Apple account for TestFlight, tester groups and App Review. | [Developer account](https://developer.apple.com/account/) · [App Store Connect](https://appstoreconnect.apple.com/) |
| GitHub | Source code, pull requests, CI and database deployment workflows. | [Project repository](https://github.com/kratijain2631/period-app) |

See [Troubleshooting and operations](TROUBLESHOOTING.md) for renewal history and service-specific setup, and [Onboarding](ONBOARDING.md) for contributor access.
