# Home design mock

A standalone HTML exploration based on the supplied home-screen reference. Open `index.html` directly, or serve this folder with a static HTTP server. Fonts and illustrations are local; no install or network connection is needed.

Click phase labels to explore the wheel, “See what this means” for details, the daily quest to set an intention, or the plus button to try a symptom check-in. Navigation and header buttons open sample panels. All data is illustrative, and check-ins/intention state reset on reload. This prototype does not connect to Apple Health or Supabase.

The reference's estimated fertile-window card is presented as an estimate. The mock is a design exploration, not a change to native screens or the cycle model.
